# Jay Gopal Tripathy — Portfolio

**Live:** [jaygopal-portfolio.vercel.app](https://jaygopal-portfolio.vercel.app)

---

### Stack

- **Framework** → React 19
- **Bundler** → Vite
- **Language** → TypeScript
- **Styling** → TailwindCSS
- **Animation** → GSAP + vecteur (magnetic cursor)
- **Deploy** → Vercel (primary) + GitHub Pages via GitHub Actions (mirror)

---

### Develop

```
npm install
npm run dev
```

### Build

```
npm run build:gh
npm run build:vercel
```

---

### Sections (top → bottom)

- **Hero** — name + tagline
- **About** — bio + skills tags
- **Tech Stack** — categorized chip cloud
- **Journey** — research & experience log
- **GitHub Stats** — live API stats + contribution graph
- **Projects** — featured work cards
- **Contact** — email, phone, location + interactive keyboard

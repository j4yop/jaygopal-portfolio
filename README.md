# Jay Gopal Tripathy — Portfolio

Personal site — React + Vite + TypeScript, NeoBrutalist design.

**Live:** [jaygopal-portfolio.vercel.app](https://jaygopal-portfolio.vercel.app)

---

### Stack

- **Framework** → React 19
- **Bundler** → Vite
- **Language** → TypeScript
- **Styling** → TailwindCSS
- **Animation** → GSAP + vecteur (magnetic cursor)
- **Deploy** → Vercel (primary) + GitHub Pages via GitHub Actions (mirror)

---

### Develop

- `npm install` — install deps
- `npm run dev` — start dev server on `localhost:5173`

### Build

- `npm run build:gh` — build for GitHub Pages (base: `/jaygopal-portfolio/`)
- `npm run build:vercel` — build for Vercel (base: `/`)

---
